# AdvOS v9.67 — notificações WhatsApp + encaminhar/compartilhar

- Adiciona contador de mensagens não lidas no botão Atendimento.
- Adiciona contador de mensagens não lidas no botão Financeiro/Jurídico.
- Mantém o contador de Encerrados separado, como indicador de conversas encerradas.
- Adiciona ativação de notificações do navegador para novas mensagens recebidas enquanto a página estiver em segundo plano.
- Notificação mostra setor, contato e prévia da mensagem.
- Adiciona “Encaminhar mensagem” para mensagens recebidas, com escolha de outro contato/cliente do escritório.
- Encaminhamento suporta texto e mídias armazenadas no AdvOS.
- Adiciona “Compartilhar mensagem” usando Web Share API quando disponível; texto usa fallback para copiar.
- Ações de encaminhar/compartilhar aparecem apenas em mensagens recebidas.
- Mantém transcrição local da v9.66 e não adiciona transcrição ao PWA.
- Nenhuma migration SQL nova.
