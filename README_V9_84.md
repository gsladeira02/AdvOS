# AdvOS v9.84

## Assinatura nativa

- Cliente: link público do próprio AdvOS, visualização obrigatória, selfie + OTP + confirmação do nome, sem desenho manual.
- Daniel Costa Ladeira: assinatura autenticada dentro do AdvOS, sem token público, OTP, selfie ou desenho manual.
- O cliente não recebe o link do segundo signatário.
- Assinaturas concluídas mostram o PDF assinado dentro da aba Assinaturas e permitem abrir/baixar.
- A área Assinaturas fica disponível no PWA.
- Cabeçalhos de segurança permitem renderização apenas same-origin do visualizador de assinatura.
- Nenhuma integração externa de assinatura é necessária.
